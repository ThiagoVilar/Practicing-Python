# Loops: for and while

Exercises from the course [Praticando Python: laços for e while](https://cursos.alura.com.br/course/praticando-python-lacos-for-while).

## What I practiced

- Using `for` and `while` loops
- Understanding the difference between the two loops
- Controlling loops with `break` and `continue`
- Writing loops in practice

## Activities

- [01 - Understanding loops](./01_understanding_loops.py): goes through a list of customers and shows each one using a for loop
- [02 - What is an infinite loop?](./02_what_is_an_infinite_loop.py): fixes a while loop that never stops by updating the counter
- [03 - How many times is the message displayed?](./03_how_many_times_is_the_message_displayed.py): shows a message exactly 5 times using a for loop
- [04 - Calculating the sum of numbers](./04_calculating_the_sum_of_numbers.py): calculates the total sum of a list of values using a for loop
- [05 - Organizing your portfolio](./05_organizing_your_portfolio.py): goes through a list of projects and shows a message when an item is missing
- [06 - Understanding the use of break](./06_understanding_the_use_of_break.py): stops a for loop as soon as a specific book is found
- [07 - Inventory control](./07_inventory_control.py): simulates book sales with a while loop until the stock runs out
- [08 - Countdown](./08_countdown.py): shows a countdown from 10 to 1 with different messages for even and odd numbers
- [09 - Usefulness of continue in loops](./09_usefulness_of_continue_in_loops.py): shows only the books in stock, skipping the ones with no stock using continue
- [10 - Login input validation](./10_login_input_validation.py): keeps asking for username and password until both meet the minimum length
